## Overview

This repository provides Rapeseed Maps for [MPRI: A Multi-phenology Index for Rapeseed Mapping Using Time-series Sentinel-1 SAR data].
MPRI is a general multi-phenology rapeseed index (MPRI) for automatic rapeseed mapping, using time-series Sentinel-1 SAR data. Central to this method is establishing the linkage between time-series SAR backscattering (including intensity and polarimetric) patterns with rapeseed phenology.
